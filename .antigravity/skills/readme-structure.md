## Ordem das secções
1. **Título + descrição curta** (1-2 frases do que o projeto faz)
2. **Badges** (build status, versão, licença), se aplicável
3. **Instalação** — passos mínimos para correr localmente
4. **Uso básico** — o exemplo mais simples possível que funcione
5. **Configuração** — variáveis de ambiente, ficheiros de config
6. **Estrutura do projeto** (opcional, só se não for óbvia)
7. **Contribuição** — como correr testes, convenções, como abrir PR
8. **Licença**

## Regras
- A secção de instalação tem de funcionar copiando e colando os comandos,
  sem passos implícitos não mencionados
- O exemplo de uso básico nunca deve exigir configuração prévia não
  explicada nesse mesmo exemplo
- Se o projeto tiver múltiplos pontos de entrada (CLI, biblioteca, API),
  separar claramente com subsecções
- Não deixar secções "TODO" ou placeholders no README publicado
